# Peer agent-orchestration projects

Documented 2026-11-05 at Mitchell's request (1:1 mt_vbi4nrhgy4, notes [dc_ka6itg9v6o](../../meeting-notes/2026-11/2026-11-05-1-1-mitchell-and-juno-notes-6itg9v6o.md)). GitHub numbers are as of 2026-11-05.

- **Ruflo** (ex-Claude Flow), rUv / ruvnet: MCP swarm toolkit, 81k stars, MIT, releases daily. ruflo.pro is an *unofficial* guide site; the real repo is github.com/ruvnet/ruflo. Card [dc_evew3jvuzw](../../../../../library/source/2026-11/2026-11-05-source-ruflo-ex-claude-flow-by-ruv-ruvnet-mcp-swar-ew3jvuzw.md).
- **Gas Town**, Steve Yegge: Go CLI "town" (Mayor, polecats, beads, merge queue). Its Wasteland federates towns, which post work and earn reputation. 18.7k stars, MIT, last release 2026-06-06. Card [dc_ofwrxgupzm](../../../../../library/source/2026-11/2026-11-05-source-gas-town-by-steve-yegge-gastownhall-gastown-wrxgupzm.md).
- **Munder Difflin**, Chaitanya Giri: desktop pixel-art office of agents, MIT core plus Pro at $20/30 days, 9.4k stars. Runs an agent-written daily SEO blog. Card [dc_rfbarrd2k2](../../../../../library/source/2026-11/2026-11-05-source-munder-difflin-munderdiffl-in-by-chaitanya-barrd2k2.md).
- **Svall**, linusroxbergh (Stockholm): macOS map of agents as robots on islands, GPL-3.0, alpha, 3 stars. No coverage found. Card [dc_z2bwa4elld](../../../../../library/source/2026-11/2026-11-05-source-svall-svall-dev-macos-map-of-claude-code-co-bwa4elld.md).
- **Comparison and outreach channels:** [dc_jk3ini7ysr](../../note/2026-11/2026-11-05-muster-town-next-to-ruflo-gas-town-munder-difflin-3ini7ysr.md). In short, all four are for one operator using their own subscription. Muster Town's difference is that several humans fund (the Bank and grants) and steer (goals and reviews) shared work, with a public record. Channels to use: Show HN, founder long-form posts, GitHub readiness (licence, README), honest comparison posts, Discord/Product Hunt, and contacting Gas Town/Wasteland and the Svall author.
