## Findings
- **Ruflo** ([dc_evew3jvuzw](../../../../../library/source/2026-11/2026-11-05-source-ruflo-ex-claude-flow-by-ruv-ruvnet-mcp-swar-ew3jvuzw.md)): ruflo.pro is **not the project's own site**. Its footer says it is an "independent educational and community resource" that sells a PDF guide. The real project is github.com/ruvnet/ruflo (formerly Claude Flow), by rUv. It is an MCP swarm toolkit with 80,966 stars, MIT licence, latest release v3.71.4 on 2026-11-05, and almost all commits are from one maintainer.
- **Gas Town** ([dc_ofwrxgupzm](../../../../../library/source/2026-11/2026-11-05-source-gas-town-by-steve-yegge-gastownhall-gastown-wrxgupzm.md)): by Steve Yegge. It is a Go CLI "town" with a Mayor, worker "polecats", a beads issue tracker and a merge queue. Its **Wasteland** federates towns: they post wanted work and earn reputation stamps. 18,711 stars, MIT, latest release v1.2.1 on 2026-06-06, and only maintenance commits since then. It spread through Yegge's Medium posts, HN, The New Stack and SD Times, plus a hosted version run by Kilo.
- **Munder Difflin** ([dc_rfbarrd2k2](../../../../../library/source/2026-11/2026-11-05-source-munder-difflin-munderdiffl-in-by-chaitanya-barrd2k2.md)): by Chaitanya Giri. A desktop app that shows agents as a pixel-art office. MIT core plus a paid Pro ($20 for 30 days or $150 for a year, one-time payment). 9,380 stars, created 2026-05-31. Its outreach covers HN, Product Hunt, Discord and social media, and its repo commits an agent-written daily "seo-engine" comparison blog post. Its reach numbers are self-reported and I could not verify them.
- **Svall** ([dc_z2bwa4elld](../../../../../library/source/2026-11/2026-11-05-source-svall-svall-dev-macos-map-of-claude-code-co-bwa4elld.md)): by linusroxbergh (Stockholm). A macOS alpha app that shows agents as robots on islands. GPL-3.0, 3 stars, release v0.27.0 on 2026-11-01. I found no coverage of it anywhere.
- **Comparison** ([dc_jk3ini7ysr](../../note/2026-11/2026-11-05-muster-town-next-to-ruflo-gas-town-munder-difflin-3ini7ysr.md)): all four are tools for one operator that run on the user's own subscription. None has pooled funding, governance by several humans, or a public record of decisions. Those are where Muster Town differs. Gas Town is the nearest in concept and Munder Difflin the nearest in look. Outreach channels we could use: Show HN, long-form posts by Mitchell, getting the GitHub repo ready (Muster Town's repo is public but has no licence file and 0 stars), honest comparison pages written by agents, Discord/Product Hunt, and contacting the Wasteland and the Svall author directly.
