- **Blocked reasons**: `GET /api/blocked` (core townBlocked). The red map badge has a hover card; clicking it opens the queue.
- **Building schedules**: table `schedules` (migrations 057, 058), core `schedules.ts`. `fireSchedules` (runtime tick) creates one assignment per run on the building queue. A schedule is one-shot (`runsAt`) or repeats (`everyHours` ≥1 / `dailyAt` UTC) until `until` (default 14 d, max 90) or for `times` runs. A run is skipped while the last run is queued or running, and missed runs collapse into one. Paused schedules don't fire. If a schedule's lane stops holding, it ends with a `schedule-ended` in-tray report.
